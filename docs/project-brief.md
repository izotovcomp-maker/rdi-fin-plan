## Общее

| Параметр | Значение |
|----------|----------|
| Название | Фин план |
| Описание | Финансовый план движения денежных средств компании по данным CRM Б24: все платежи (доходы «+», расходы «−») с датой и суммой, свод по месяцам, реестр движений, разрез по объектам, остаток нарастающим итогом |
| Клиент | ООО «РДИ» (RDI) |
| Портал Б24 | ooordi.bitrix24.ru |
| Дата старта | 2026-10-09 |

## Входной контекст

Материалы заказчика и проекта лежат в `source/`; их описание — в [source/INDEX.md](../source/INDEX.md).
