## Где мы сейчас

Приложение задеплоено на prod (`https://rub24.blackboxbegin.space/rdi-fin-plan/`), блок Caddy вставлен, local-app зарегистрирован на `ooordi.bitrix24.ru`, credentials в `env.php`, установка и access-flow прошли (токены и сессии в `data/`). На реальных данных выявили и починили расхождения: `result.items`-обёртка, молчаливая потеря стандартных полей в select при `useOriginalUfNames=Y` → перешли на `select: ['*']` (D-008), знаки расходов, признак факта по `UF_CRM_12_PAY_FACT`, фикс `dealLabel`. В приложении есть админ-окно «Диагностика» для снятия сырых ответов портала. Заказчик дозаполнил «Дата план» у оплат; ждём подтверждения, что свод/реестр/по объекту теперь показываются корректно.
