- **Репозиторий:** `/templates/tmpl-b24-php-kilo` — шаблон single-tenant B24 local-app на PHP
  (PHP без composer, vanilla JS, файловый store `<?php exit;?>`, деплой rsync).
- **Происхождение:** ядро `www/` — оригинал `_b24-single-php` от команды интеграторов

  харнессами и моделями** на одном и том же проекте, чтобы подобрать оптимальную связку.
  Первый на очереди — **Kilo Code**; затем Claude Code (уже работает) и другие.

### Режимы доступа — три режима с переключателем (сделано 2026-10-07)
**Решение владельца (2026-10-07): вопрос про режимы доступа из онбординга убран.** Режим и списки администратор
выбирает сам кнопкой «Доступ» после установки; по умолчанию — по отделам (`DEFAULT_ACCESS_MODE`,

  (смена режима/галочки отзывает доступ сразу). `DEFAULT_ACCESS_MODE` (`departments|users|all`) — начальный режим
  проекта (по умолчанию `departments`); режим и списки администратор меняет кнопкой «Доступ».

  активные сотрудники; без `mbstring` (сортировка — в браузере).
- `www/api/access.php`: GET (режим, отделы, списки), `GET ?list=users`, POST (`mode`, `allowedDepartments`, `allowedUsers`).
- Окно «Доступ»: переключатель из трёх режимов; список людей — Фамилия Имя, почта, id, поиск, счётчик.
